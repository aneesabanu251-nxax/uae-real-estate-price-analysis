# UAE Real Estate Power BI Dashboard

This Power BI dashboard provides an interactive analysis of UAE real estate property listings.

## Dashboard Overview

The dashboard analyzes 492 property listings across 66 areas in the UAE.

## Key KPIs

- Total Properties: 492
- Average Property Price: AED 2.17M
- Maximum Property Price: AED 15M
- Total Areas: 66

## Key Visualizations

- Top 10 Listed Areas in UAE
- Property Price by Area
- Bathroom vs Price Analysis
- Price Distribution
- Monthly Property Listing Trends
- Bedroom-wise Price Analysis

## Interactive Filters

- Price
- Year
- Area
- Bedroom

## Tools Used

- Power BI
